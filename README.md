# Worthathon — Worth & Willi

A simple GitHub Pages website for the Worth & Willi Worthathon marathon event.

## Files

- `index.html` — page content
- `styles.css` — Worth & Willi green/blue design
- `script.js` — event countdown/status logic

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `worthathon`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will give you a public Pages URL.
