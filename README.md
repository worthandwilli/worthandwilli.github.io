# Worth & Willi Server Guide (GitHub Pages)

This repo hosts the public server guide for Discord:
- Main questline order
- Helpful commands for normal players
- Plugin categories and what they do

## How to publish (GitHub Pages)
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Save

Your site URL will appear in the Pages section.

## Editing
- Update `index.html` for text/sections
- Update `script.js` to add/remove commands
- Update `styles.css` for appearance
